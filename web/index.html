Board & hardware guide ↗

My board doesn't appear, or won't connect.

Use desktop Chrome or Edge and a USB data cable, not a charge-only cable. Close Arduino, serial monitors, and any other tab using the device. Try a direct USB port instead of a hub.

If it still won't connect: unplug USB, hold BOOT, reconnect USB while holding it, then release BOOT and try again. Select the Espressif USB Serial/JTAG device. If ORBIT doesn't respond after installation, turn the board fully off with PWR, then turn it back on. Unplugging USB alone won't turn off a battery-powered board.

Linux may require serial-port access for your user account; follow your distribution's device-permission guidance. On a managed computer, ask your administrator rather than disabling security settings.

Will an update erase my songs?

Choose Already has ORBIT. Updates write only the application and leave ORBIT's song storage, recordings, and partition table untouched. The installer refuses an update if the existing layout doesn't match.

A new board also writes the bootloader, partition table, and boot support. Use it only for first installation or when you are happy to replace other firmware and potentially lose its data.

What happens if I unplug it halfway through?

The installation may be incomplete. Reconnect, use BOOT if needed, and retry the same installation type. Don't switch to first installation to fix a routine update. Keep the USB cable connected and the tab open until verification finishes.

Where does this firmware come from?

Each successful publication from the ORBIT project's main branch creates a numbered GitHub release. This page installs that same build, with download checksums and on-device verification. All flashing runs locally in your browser.
